# n8n-instagram-lead-crm
Lead CRM in n8n: Webhook + Code + AI Agent (Gemini) + Data table
Webhook receives a lead, JavaScript builds a WhatsApp link, a Gemini AI agent writes a reply, and the lead is saved in an n8n Data table. Import the JSON, add your own Google Gemini credential and create a Data table "leads" with columns: username, message, status, whatsapp_link, reply.
